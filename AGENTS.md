# Repository instructions

- After every completed change, run the relevant checks, commit the change, and push the commit to the current branch's remote. Do this before reporting the work as complete.
- Use a clear commit message describing the change. Never force-push or discard existing work.
- If a check, commit, or push fails, resolve the failure when possible and report any remaining blocker explicitly.
- Validate TypeScript changes with `bun run typecheck` and run relevant tests with `bun test`.
